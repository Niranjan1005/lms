# Trials & Add-ons

## Trials

- Default 7 days, dynamically configurable.
- Start at first successful feature activation.
- Represented by a signed time-limited grant.
- Eligibility tracked centrally with auditable overrides/campaigns.

## Add-ons

Subscription add-ons normally run only until the active base subscription end date.

~~~text
Base: Jan 1 ---------------- Dec 31
PPE:                 Sep 1 -- Dec 31
Renewal: Jan 1 ---- Base + PPE together
~~~

Perpetual base licenses may have separately expiring add-ons.
