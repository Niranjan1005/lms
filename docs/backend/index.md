# Backend Engineering

Baseline stack: Python 3.12, FastAPI, PostgreSQL, SQLAlchemy, Alembic, Pydantic, React/Vite/TypeScript.

Start as a modular monolith with explicit domains: identity/access, customers/sites, devices/enrollment, catalog, entitlements, policy, grants, capacity, marketplace, releases, artifacts, deployments, renewals, offline exchange, telemetry, notifications, audit and signing gateway.
