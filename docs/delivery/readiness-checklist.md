# Development Readiness Checklist

- [ ] Business outcome defined
- [ ] Scope/non-goals clear
- [ ] State machine documented
- [ ] DB ownership and transaction boundaries known
- [ ] API contracts drafted
- [ ] Authorization/tenant scope defined
- [ ] Offline behaviour defined
- [ ] Failure and rollback defined
- [ ] Audit events identified
- [ ] Threats reviewed
- [ ] Capacity impact considered
- [ ] QA acceptance criteria written
- [ ] ADR created for material design choices
- [ ] Team ownership agreed
