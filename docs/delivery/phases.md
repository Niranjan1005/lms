# Implementation Phases

1. Trust foundation — identity, grant schema, verifier, enrollment.
2. Registry & licensing — customer/site/device, entitlement pools, allocations, base activation.
3. Hardware & capacity — inventory, snapshots, benchmark profiles, combined workload.
4. Marketplace & release management — catalog, trials, purchase requests, package repository, Stable/LTS.
5. Model OTA & deployment — encrypted models, model inventory, release sets, maintenance windows, rollback.
6. Lifecycle — renewal, offline validity, grace, check-in, revocation, rehost, decommission.
7. Hardening — VAPT, DR, operational runbooks, ERP sync, production readiness.
