# Terminology

| Term | Meaning |
|---|---|
| Entitlement | Central commercial right purchased or granted to a customer. |
| Entitlement Pool | Quantity/rights available to a customer for allocation. |
| Allocation | Distribution of pooled rights to devices/sites. |
| Grant | Signed, device-bound executable permission derived from entitlement and policy. |
| Trial Grant | Time-limited signed grant; default 7 days unless overridden. |
| Offline Validity | Time a device may continue without authorized sync/check-in. |
| Grace | Restricted period after commercial expiry or policy condition. |
| Release | Versioned application/feature/UI/runtime package metadata. |
| Model Release | Independently versioned encrypted AI model artifact. |
| Release Set | Coherent application, feature, UI, runtime and model snapshot for deployment/rollback. |
| Capacity Assessment | Combined workload feasibility evaluation using inventory and benchmark evidence. |
