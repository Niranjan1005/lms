# Inventory & Benchmarking

Stable inventory includes CPU, RAM, GPU/accelerator, storage, OS/kernel, drivers, CUDA/TensorRT/DeepStream/runtime, camera characteristics and installed models/services.

Dynamic snapshots include available RAM, free disk, GPU utilization, temperature, throttling, active streams and current workload.

Capacity decisions use versioned benchmark profiles covering hardware, model/version, resolution, FPS, backend, decode pipeline and concurrent workloads.
